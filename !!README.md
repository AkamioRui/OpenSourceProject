This project was initiated during the Spring semester of the 113 academic year as the final project for the course Open Source Practice. 
The objective was to develop a web application supported by a fully functional relational database.
After careful consideration, we decided to create a message board-style platform named LetMeKnow, inspired by popular social media sites like Reddit. 
The concept was simple yet powerful—allow users to post and interact in a community-driven environment.
The name **LetMeKnow** was chosen with great purpose. 
It was inspired by a viral social media audio track, which resonated with the way social interactions often happen in online spaces. 
Additionally, Reddit’s widespread use among students made it a fitting reference for the type of platform we envisioned. 
By merging these two influences, we felt the concept came together naturally, leading to the development of our final product.
